# Software Factory

Use Node >=22 and built-in modules only. macOS/Linux are the supported platforms.
Run `npm test` and `npm run check` before delivery. Preserve the rule that completed
tasks require fresh executable verification, review and observed delivery.
Keep runtime data and personal paths outside source. Never launch paid model APIs.
Start feature branches from main; draft PRs target main or an explicitly selected
lower stack layer. No implicit merges, releases or deletion of task worktrees.
